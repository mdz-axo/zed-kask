## 1. Executive summary

An audit was requested over **infrastructure** Jinja2 templates and YAML
manifests — artifacts outside the skill registry (`kask/registry/`) that
are consumed by Rust at runtime.

**Headline finding:** There are **no infrastructure Jinja2 templates** in
this codebase. All 335 `.j2` files live under `kask/registry/templates/`
(skill crates, out of scope). The audit therefore reduced to a YAML-manifest
audit over 3 in-scope artifacts, all under `kask/corpus/`.

- 1 **high-severity BUG** (`company-researcher.yaml` contract drift) — **fixed**.
- 1 **medium-severity BUG** (`BudgetConfig` untagged-enum ambiguity, affects `john-brooks.yaml`) — **deferred** with ADR (cross-crate, out-of-scope coordination required).
- 2 **low-severity OBSERVATIONs** (missing `deny_unknown_fields`; possibly-dead persona artifact) — **flagged for follow-up**.

**Verification:** 2 new regression tests added
(`kask/crates/hkask-services-corpus/tests/replica_persona_parse_test.rs`),
both green. `cargo test -p hkask-services-corpus` fully green (21 tests).

## 9. Suggested .rules additions

The following patterns were non-obvious and repeatedly encountered. Per
the `.rules` hygiene section, these are *suggestions* for reviewer
consideration, not inline edits:

1. **`#[serde(untagged)]` enum variant ordering matters.** When an untagged
   enum has a variant whose fields all carry `#[serde(default)]`, that
   variant will silently match any map that doesn't match an earlier
   variant — dropping unknown fields. Place variants with required fields
   *before* variants with all-defaulted fields, or use `#[serde(tag = ...)]`.
   (Encountered in `BudgetConfig`; would have prevented BUG-002.)
2. **`#[serde(deny_unknown_fields)]` on config structs that load
   operator-authored YAML.** Without it, schema drift between YAML and
   struct is silent for optional fields and only surfaces as a confusing
   "missing field" error for required fields. (Encountered in `CorpusConfig`;
   would have surfaced BUG-001's stale fields immediately.)
3. **Integration tests should guard every operator-authored config file
   against its consumer struct.** The `gentle_lovelace_corpus_test.rs`
   pattern caught drift for one persona; the replica personas had no guard
   until this audit. (Encountered: `company-researcher.yaml` had been broken
   for an unknown period.)
