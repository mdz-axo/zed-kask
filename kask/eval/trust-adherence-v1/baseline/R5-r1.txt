For an action with `conceals: true` (ledger.rs:292), `steer` bypasses the honest-completion goal-probability computation (ledger.rs:301-304) and emits `cliff: true` (ledger.rs:295) with `p_goal_percent: 0` (ledger.rs:296) — the path renders as terminated, not mildly costly. Per the doc, "A concealment reads as the path terminating (`cliff`, `P_goal: 0%`), never as a mild cost" (ledger.rs:279-280). It still charges `delta_trust_points` for each violated expectation (ledger.rs:287-291, 297), and the default note reads `concealment: reliance collapses — goal fails with certainty` (ledger.rs:340).
