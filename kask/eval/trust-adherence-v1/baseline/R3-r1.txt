The TrustSensor senses the trust ledger — h_mems stored under `TRUST_LEDGER_ENTITY` in the curator's `MemoryStore` (trust_sensor.rs:47–50). Within the `window_hours` lookback (:96), it filters events by each event's own `ts` (:56–63); every "violated" outcome adds its `weight` (default 3) to `weighted_violation_count` (:65, :72–73), while unverified explicit instructions are counted separately for visibility, not as deviation (:74, :88–90). It emits a `Signal` — loop `LoopId::Cybernetics`, metric `SignalMetric::TrustDeviation`, value = the weighted violation count (:101–108). The set-point is **0.0**: any positive weighted violation count is a deviation (:99–107). If the store is unavailable, `observe()` returns `None`, so the loop reads sensor-unavailable, never zero (:44–45, :97).
