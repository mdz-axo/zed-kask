An `unverified` ledger event records a claim whose outcome was asserted without an executed oracle — `oracle_note` is `None`, the judgment was the model's alone. Recording it keeps the claim's epistemic class visible on the row itself: asserted, not checked.

Silence would be worse than an honest gap: an absent state cannot be distinguished from a ledger that never recorded the claim at all, so reliance decisions would read nothing where a caveat belongs. The verification state is kept, violated, or unverified — never silent — so every recorded expectation carries exactly the evidence class it earned.
